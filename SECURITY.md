# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue. Use GitHub's private reporting:
<https://github.com/tranvanhuy-hichan/dev-dock/security/advisories/new>

Include steps to reproduce, the affected version and the impact. We aim to acknowledge within 7 days.

## Scope notes

DevDock runs entirely on your machine, but it can run commands, read `.env` files and talk to Docker, databases and Ollama. Never share logs or screenshots that contain secrets. Keep the app updated, and report anything that could leak or expose secrets.
